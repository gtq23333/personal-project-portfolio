### 3. `[In Use]` 英语口语对练与交互学习 Agent

支持端到端语音情景口语对练，并实时存储对练历史，自动将不够地道的表达记录并生成针对性练习题 + 笔记，可以进行复习。

### 4. `[In Use]` 面经解析 - LLM 自动作答与学习笔记系统

支持把面经截图 / 文本直接导入并自动抽取面试题，LLM 自主作答。含 GUI，答案可编辑，支持分级标记难题或重要题。

### 5. `[In Dev]` Multi-Agent AI 漫剧工厂

核心设计：

- **剧本创作 Agent**：支持小说自动改剧本，支持从零到一访谈多轮交互生成剧本；
- **导演与分镜 Agent**：自动根据设定的时长区间从剧本中提取分镜；
- **美术与媒体资产管理**：设有专门的美术资产管理系统，能自动生成 / 手动替换剧本中的人物、地点等实体的设定图 / 参考图等美术资产，以及参考声音 / 视频等媒体资产；
- **美术资产检索引擎**：根据分镜动态检索、按需披露并绑定每个分镜的美术及媒体资产；
- **AIGC 提示词撰写 Agent**：根据分镜信息与美术资产撰写最终用于生成视频片段的专业级提示词；
- **质检 Agent**：通过抽帧和 VLM 检查视频生成质量，过滤低质视频入轨；
- **剪辑预览与视频片段管理**：规则化拼接生成的视频片段，支持单片段修改提示词和重新生成。
